### 4. ☁️ know-my-health — AWS CLI Observability Tool

[![Python](https://img.shields.io/badge/Python-boto3-3776AB?style=flat-square&logo=python)](https://github.com/codezenithdev/health_status)
[![AWS](https://img.shields.io/badge/AWS-EC2_EBS_ELB_S3-FF9900?style=flat-square&logo=amazonwebservices)](https://github.com/codezenithdev/health_status)

> CLI that aggregates and visualizes live metrics from EC2, EBS, ELB, and S3 in one tabular view.

```bash
# Real-time EC2 metrics with bastion SSH tunneling
know-my-health list-instances --profile prod --bastion-ip 10.0.0.1 --key-path ~/.ssh/key.pem --visualize

# AWS cost explorer
know-my-health list-cost --profile prod --start-date 2025-01-01 --end-date 2025-01-31
```

- Covers CPU · RAM · IO wait · EBS IOPS/throughput · ELB target group health · S3 ACLs · Cost Explorer
- Multi-profile · tag-based filtering · `--visualize` flag

🔗 **[codezenithdev/health_status](https://github.com/codezenithdev/health_status)**
